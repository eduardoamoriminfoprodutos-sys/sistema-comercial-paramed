# Sistema Comercial PARAmed

Metas e faturamento diário. Dados sincronizados via Supabase: lançou num aparelho,
aparece nos outros.

- **Calendário de faturamento** — lançamento dia a dia, por vendedora
- **Visão geral da loja** — meta, realizado, ritmo e ranking
- **Reunião individual** — apresentação da meta de cada vendedora
